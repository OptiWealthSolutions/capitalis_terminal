# IDÉES DE VIDÉOS - FORMAT LONG (1/semaine)

## 1. Lifestyle : 24h dans ma vie de trader et investisseur
- **Objectif** : Humaniser la marque, montrer la discipline et le "Build in Public".
- **Points clés** : Routine matinale, analyse macro, sessions de code pour CAPITALIS, gestion de portefeuille, sport/équilibre.
- **Hook** : "Ce n'est pas ce que vous voyez sur Instagram. Voici la réalité du trading systématique."

## 2. Par où commencer pour investir ?
- **Objectif** : Capturer l'audience "Novice Ambitieux".
- **Points clés** : Définition des objectifs, choix du courtier, importance du système avant le capital, introduction au scoring d'actifs.
- **Hook** : "Oubliez les signaux de trading. Voici comment construire une base solide en 2026."

## 3. Mon processus de recherche macroéconomique journalière et hebdomadaire
- **Objectif** : Établir l'autorité d'expert (Confirmed Investor).
- **Points clés** : Sources de données (FRED, Bloomberg, etc.), analyse des corrélations, impact sur le portefeuille CAPITALIS, outils utilisés pour l'automatisation.
- **Hook** : "Comment je traite des téraoctets de données macro en 30 minutes chaque matin."
